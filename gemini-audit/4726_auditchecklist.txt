   ```

   ```

2. **glob/Vite glob imports** — `import.meta.glob()` pattern:
   ```
   rg "import\.meta\.glob" src/
   ```

3. **Svelte component variables** — Components assigned to variables then rendered dynamically:
   ```
   rg "svelte:component" src/ --type svelte
   ```
   Also check for Svelte 5 dynamic component rendering (components as values without `<svelte:component>`).

4. **Re-export barrels** — `export * from` or `export { X } from` patterns that re-export from other modules:
   ```
   rg "export \* from|export \{.*\} from" src/lib/
   ```

5. **Config/registry patterns** — Objects mapping string keys to component/module paths:
   ```
   rg "component:|lazy:|loadComponent|componentMap|registry" src/
   ```

6. **URL-based references** — fetch() calls that reference internal API routes (these wire server endpoints as dependencies):
   ```
   rg "fetch\(['\`\"]\/api\/" src/ --type svelte
   ```
   Count unique API paths referenced.

   ```
   rg "export const load" src/routes/
   ```

8. **Event-based wiring** — CustomEvent dispatchers that indirectly connect components:
   ```
   rg "CustomEvent|dispatchEvent|addEventListener" src/ --type svelte --type ts
   ```

9. **Vite define/alias** — Check vite.config.ts for path aliases that could hide imports.
